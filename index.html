About free mode

This version runs its built-in generators in your browser. It does not call a paid API, and it does not provide unlimited AI model inference or generate finished images. Later, you can connect an open model you host yourself or a service with a free allowance.

Provider notes

Local mode requires an OpenAI-compatible chat-completions endpoint, such as an Ollama-compatible gateway. Online mode requires your own HTTPS backend proxy. GitHub Pages is static hosting and cannot safely hide private API keys.
